# Contribuindo com o CleanBrowser

Obrigado pelo interesse! 🎉

## Rodando o projeto

```bash
git clone https://github.com/lucasvitancourt/CleanBrowser.git
cd CleanBrowser
npm install
npm start
```

## Fluxo

1. Faça um fork e crie uma branch: `git checkout -b minha-melhoria`
2. Faça commits pequenos e com mensagens claras (ex.: `feat: atalho para fixar aba`)
3. Teste com `npm start` e, se mexer no empacotamento, com `npm run build`
4. Abra um pull request explicando o que mudou e por quê

## Dúvidas e ideias

- Dúvidas: use a aba **Discussions → Q&A**
- Bugs e sugestões: abra uma **Issue** usando os modelos disponíveis
